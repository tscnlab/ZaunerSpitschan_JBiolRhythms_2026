# Execution and verification record

The two isolated scenarios completed all ten stages: primary near-eye/chest fitting and inference, validation, attribution, model sensitivities, descriptive outputs, MEQ sensitivity, daylength inference, daylength validation, noncyclic sensitivity, and PRC/Emens integration. `comparison/completed_stages.csv` records their input signatures and completion times. Each scenario's `results/provenance/` contains stage-specific R sessions and run records.

The clock-time and phase attribution runs each contain all 128 subset masks in each scenario. `verify-stages.R` checks this coverage, the fixed full-model AR coefficient, Shapley additivity, the simultaneous-inference convention, local support, and completed-stage signatures. It also reruns the original noncyclic basis/constraint checks, substituting exact agreement with the matched cyclic sample for the original fixed-140 assertion. Both scenarios pass all 20 stage checks; `compare.R` passes all 27 comparison and source-preservation checks.

Early primary and validation invocations used an Rscript driver that was edited during execution. Rscript's incremental parsing produced trailing parse errors after the calculations had completed. The primary and validation stages were subsequently replayed to clean completion from their signed model caches using `Rscript -e 'source(...)'`, which parses the complete driver before execution. The final successful logs are `primary_clean.log` and `validation_clean.log` in each scenario's `results/logs/` directory. No model refit or statistical specification was changed by this replay.

An export-only target-support table initially included unused factor levels Q2 and Q3. `refresh-support.R` removed those unused rows and verified exact equality of all relevant Q1/Q4 support counts and unchanged daylength-inference hashes. Its successful records are `support_refresh.log`. The primary and daylength inference support masks were unaffected.
